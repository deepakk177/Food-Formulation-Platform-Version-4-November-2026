## 2. Authentication and Authorization Behaviors

### Route Guard Behavior
- **Public Routes:**
  - `/` (Landing Page)
  - `/login` (Sign-in form)
  - `/register` and `/signup` (Registration form)
  - `/dashboard` (Platform Overview — accessible with demo context)
  - `/dashboard/formulate/guided` (5-Stage Guided Formulation Wizard — accessible without authentication friction for rapid prototyping)
  - `/dashboard/ingredients` (Ingredient Catalog)
  - `/dashboard/knowledge-graph` (Knowledge Graph Explorer)
- **Protected Routes with Token Enforcement:**
  - `/dashboard/formulate/expert` (Expert Manual Formulation Studio)
  - `/dashboard/compliance` (Regulatory Compliance Matrix)
  - Both routes verify the presence of a valid JWT token in local storage / session state. When accessed by an unauthenticated guest browser directly without a session cookie, the Next.js router seamlessly redirects the client to `/login?redirect=...`.
  - **Resolution during audit:** When tested with a registered user session, both routes loaded and functioned completely without error.

## 3. Database & Service Integrations: Live vs. Fallback

### Neo4j Enterprise Graph Engine
- **Observed State:** The external Neo4j daemon (`bolt://localhost:7687`) was not active as a system background service during the test run.
- **Architectural Fallback:** The backend `KnowledgeGraphClient` contains an automated fallback handler. When the Neo4j socket connection fails, the system automatically redirects all graph queries to the embedded SQLite relational database (`tcs_food_formulator_kg.db`).
- **User Impact:** **Zero degradation.** The frontend Knowledge Graph visualizer and ingredient lookup continued to function seamlessly, pulling node-link relationships directly from the 23,893 records in SQLite.

### Qdrant Vector Retrieval Engine
- **Observed State:** Qdrant vector database (`http://localhost:6333`) was not active as an independent microservice container.
- **Architectural Fallback:** The platform leverages SQLite full-text search (FTS) and keyword classification to perform semantic ingredient matching.
- **User Impact:** High-speed, local entity extraction and ingredient retrieval work without external cloud dependencies.

---

## 4. Export & Download Behaviors

### Technical Dossier Export
- **Observed Mechanism:** Clicking the "Export Technical Dossier" button on Stage 5 of the Guided Formulator triggers client-side print formatting (`window.print()`).
- **Styling Support:** The frontend includes an `@media print` CSS stylesheet that cleanly formats the 7-tab analytical report into a printer-friendly layout for saving as a PDF document.
- **Technical Gap:** There is currently no backend headless Chromium service (such as Puppeteer/WeasyPrint) generating an automated server-side binary `.pdf` download endpoint. The client-side print-to-PDF approach is fully functional and requires zero server overhead.

---

## 5. UI Telemetry vs. Physical Sensor Simulation

### Processing Parameters (Stage 5 - Tab 3)
- The mixing sequences, shear rates (e.g. $1200\text{ rpm}$), and thermal treatment curves ($78^\circ\text{C}$ for 30s) are deterministically generated by food engineering rules mapped to product categories.
- They are not connected to a live factory SCADA/PLC IoT data stream. This is consistent with an R&D formulation platform prior to pilot plant scale-up.
